# Notebooks Directory

This directory contains Jupyter notebooks for experimentation and demonstration of the Auto Property project.

## Purpose

These notebooks serve several purposes:
- Exploratory data analysis
- Model experimentation and evaluation
- Visualization of results
- Demonstration of the project's capabilities
- Tutorial-style examples

## Recommended Notebooks

Consider creating the following notebooks:

1. **Data Exploration.ipynb**
   - Analyze raw data
   - Visualize text properties
   - Test preprocessing functions

2. **RAG Pipeline.ipynb**
   - Step-by-step implementation of the RAG approach
   - Visualization of embeddings
   - Examples of property extraction

3. **SLM Training.ipynb**
   - Data preparation for fine-tuning
   - Model training process
   - Evaluation of different model architectures

4. **Evaluation.ipynb**
   - Comparison of RAG vs SLM approaches
   - Performance metrics visualization
   - Error analysis

## Usage

To run these notebooks:

1. Ensure you have installed all dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Start Jupyter:
   ```bash
   jupyter notebook
   ```

3. Navigate to the notebooks directory and open the desired notebook

## Best Practices

- Keep notebooks clean and well-documented
- Include markdown cells explaining the purpose of each section
- Save intermediate results to avoid rerunning expensive operations
- Consider using notebook extensions like `nbextensions` for better organization
